# ECHO 安装包（macOS，给同事）

## 怎么用（三句话）

1. 把这个文件夹**整个**交给你的 AI 助手（Claude Code / Cursor / DSH……都可以），
   告诉它：**「按 echo-install 这个技能给我装 ECHO」**。
2. 它会问你几件事（装到哪个目录、要哪种转写、要不要唤醒词……）——**照着选就行**，不确定就用它推荐的。
3. 剩下的它自己装：环境用 **Homebrew**（`python@3.11` + `portaudio`），依赖来自 **PyPI**，
   模型来自 **ModelScope / hf-mirror** 镜像 —— **不需要 git，也不需要 GitHub**。

## 包里有什么

| 文件 | 说明 |
|---|---|
| `ECHO/` | ECHO 主程序（**已经解开好了**，约 5.6 MB，必备）。交给助手去装，你不用管 |
| `echo-install/` | 安装技能：`SKILL.md`（给助手看的步骤）+ `scripts/` 里的脚本（Windows 用 `.ps1`，mac 用 `.sh`） |
| `BUILD-INFO.txt` / `SHA256SUMS.txt` | 这个包的身份与各文件校验值（可选，想核对时用） |

> mac 上**没有** `install.ps1` 那套（那是 Windows 专属）。助手会跑：
> `ECHO/mac/setup_mac.sh`（建环境）→ 把 `ECHO/` 放到最终位置 → `mac/start_mac.sh`（启动）→
> `echo-install/scripts/echo-install-components.sh`（按你的选择装引擎、下模型、写设置、登记）。
> 如果你的助手说"不知道该跑哪个"，把这几条发它。

装完助手会**登记安装结果**，所以打开 ECHO 会**直接进仪表盘**（不会再把你塞进向导页）。
万一还有没装好的，面板顶部会明确写"还缺什么、怎么补"，不用自己猜。

## 开始之前

| 要求 | 怎么确认 |
|---|---|
| macOS **14.0 或更新** | `sw_vers -productVersion` |
| 已装 [Homebrew](https://brew.sh) | `brew --version`（没装就先装它，助手会提示） |
| 磁盘 ≥ 5 GB 空闲 | `df -h ~` |
| 能上网 | 首次要装依赖、下模型 |

## 装完大概是这样

- 安装目录约 **0.5–1 GB**（主程序 + 运行环境 + 你选的模型）。
- **能用**：录音 → 本机转成文字、会议录音 + 文字稿、浏览器打开面板
  （`http://127.0.0.1:8970`，真实端口在数据目录的 `echo-port.txt` 里）。
- **语音朗读默认会出网**：把**被朗读的那段文字**发给微软；想全离线就在设置里把
  「语音合成引擎」换成离线引擎。
- **录音、文字稿、数据库都在你自己电脑上**（mac 上是 `~/Library/Application Support/ECHO`），不上传。

## 三件"还没做完"的事（**不是你的操作问题**，如实记录即可）

1. **还没做代码签名与公证** —— 首次运行会提示「来自身份不明的开发者」。
   右键 →「打开」，或去「系统设置 → 隐私与安全性」里允许一次。
2. **要系统授权**：麦克风（录音）、辅助功能 / 输入监控（全局热键）——
   首次会弹窗，**必须你人工点一下**，助手代替不了。
3. **右缘浮动条**需要 Apple Command Line Tools（`xcode-select --install`）后编译；
   **不装也能用**：直接用浏览器打开面板。

## 遇到问题

- 助手说某个引擎 **「还不能用」**：它会在最后逐个 `import` 复核；把那段输出原样发回即可
  （常见的只是某个包没装上，加国内 pip 镜像重跑就好）。
- 语音转写一直不出字：确认麦克风授权给了、面板里选的转写方式已就绪。
- 其它任何卡住/报错：**把助手那段输出原样发回来**就行 —— 不要自己改配置。
