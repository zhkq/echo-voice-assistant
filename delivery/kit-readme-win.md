# ECHO 安装包（给同事）

## 怎么用（最省事：双击）

1. **双击 `装我.cmd`**（就在这个文件夹里）。
   * 如果资料夹里只有 `ECHO-kit-*.zip`（还没解开），**它会自己解开**——你不用右键解压。
2. 它会问：**装到哪个目录** —— 回车用默认（`D:\ECHO`，没有 D 盘就是 `C:\ECHO`）。
3. 它还会**确保 DeepSeek Harness 桌面端已装好** —— 这是 ECHO 的 DSH 的**唯一程序来源**：
   * **已装**：直接用（不重装，也不动它的配置）。
   * **没装**：从官方地址下载最新 Windows 安装包并静默安装（约 277 MB，**不在 ECHO 交付包里**；
     所以每次装/升级拿到的都是官方最新版）。
   * **桌面端正在运行**：安装程序不会覆盖，会提示你先退出，并继续用现有 CLI。
   **不需要 Node.js，也不需要 npm** —— 桌面端自带无头 `dsh`。
4. 剩下的它自己做：准备好运行环境、依赖，写好设置，把服务起起来、**拉起 DSH**，
   最后**把面板地址打印出来**（形如 `http://127.0.0.1:8970/`）。打开它就行。
5. 快装完时它会问**一件小事：会议转写用哪台 GPU 机器**（见下）。

> 包里带 `bundle\` 时，**装的过程不下载**运行环境 / 依赖 —— 全从包里拿。**不再带转写模型**（2026-10-31 起客户端不做本地转写）。
> DSH 只有一套：官方桌面端自带的那个（安装器只负责保证它已装；官方桌面端本身不进交付包）。
> 没有 `bundle\` 时那三样走联网安装（python.org / 国内 PyPI 镜像 / ModelScope）。

## DSH 只有一套：官方桌面端自带的 dsh

ECHO 的智能体（会议纪要 / 归档 / 语音指令）用的是 **官方 DeepSeek Harness 桌面端**自带的
无头 `dsh`：

```text
%LOCALAPPDATA%\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd
```

* 安装器只负责**保证它已安装**：已装就复用，没装就下载官方安装包静默安装。
* **不再安装 npm 包、不需要系统 Node.js**，也没有 `<安装根>\harness\dsh` 或独立 `DSH_HOME`。
* DSH 的家目录固定是 `%USERPROFILE%\.dsh`（桌面端自己的那份），ECHO 不另建、不改。
* 装完 ECHO 会**随启动自动拉起 DSH**（设置 `dshAutoStart`，默认开）；面板里的
  **「打开 DSH 界面」**可以跳到它。无头运行**不需要登录**；第一次在面板里打开桌面界面时
  可能弹一次桌面端登录，按需登录即可（不影响后台无头运行）。
* 桌面端正在运行时安装器不会覆盖，会提示先退出，并继续用现有 CLI。

装的过程中窗口一直开着，**出错也不会一闪而过**（末尾会停住等你按键），把那段输出发回来即可。

## 已经装过 ECHO：再双击就是升级

如果选的目录里已经有 ECHO（`echo-core\app\main.py` 存在），`装我.cmd` 会走**升级**，只更新核心代码：

| 会更新 | 不会动 |
|---|---|
| 程序代码：界面 + 核心功能（`app` / `web` / `sidebar` / `scripts`） | 数据库与全部设置（含转写 / 会议模型的选择） |
|  | 会议、文字稿、纪要 |
|  | 已有模型权重（不下载、不替换、不删） |
|  | 后端地址、配对、「允许音频去哪」 |
|  | 手机 / 手表配置 |
|  | 智能体配置（`dshAutoStart` 等；不重装官方桌面端，也不改它的 `~/.dsh`） |

- 升级前会**先停 ECHO 与边条**（否则代码文件被占用），装完自动拉起；**正在录音时会拒绝**，先结束录音再跑。
- 升级默认**不重装/不降级 DSH**；只有你同意升级 DSH 时，才会重新下载 / 静默安装官方桌面端
  （这时先退出 DeepSeek Harness 免得安装器拒绝覆盖）。它只换程序文件，智能体配置一个字不改。
- 升级前自动把数据库备份到 `data\echo.db.bak-before-upgrade-<时间>`。
- 版本相同也能跑（用于修复被改坏的安装），不会删你的数据。

## 装到最后会问一句：后端（会议转写那台 GPU 机器）怎么来

三个答案，选一个就行（选 3 以后再配也完全可以，面板「能力」页签里随时能弄）：

| 选 | 你会被问到 / 它做什么 |
|---|---|
| **1) 用别人给的后端** | 把管理员给你的**配对串**（`echo://pair?host=…&code=…`）贴进去 —— 当场配对。配对串是一次性的，过期就让管理员重发一张。 |
| **2) 本机自己跑** | 这台机器有 NVIDIA 卡时才选。它会用**这个资料夹里**的后端包：有 `ECHO-backend-offline-*.zip`（**离线包**）就**直接复制启用、零下载**；只有 `ECHO-backend-portable-*.zip`（**薄包**，20 MB，只带解释器）就把它放好，然后**自动开始下载依赖**（约 3 GB，十几分钟，面板「能力」里能看进度）。 |
| **3) 先不配** | 什么都不做。以后在面板「能力」页签里配。 |

> **想零下载就先要那份离线包**：把 `ECHO-backend-offline-*.zip` 和 `装我.cmd` 放在**一起**，
> 装的时候选 2 就是"复制启用"，不用等 3 GB 下载。两个后端 zip 都没有时选 2 也没关系——
> 它会告诉你把哪份 zip 放到哪里。

## 也能交给 AI 助手（原来的路）

1. 把这个文件夹整个交给你的 AI 助手（Claude Code / Cursor / DSH……都可以），
   告诉它：**「按 echo-install 这个技能给我装 ECHO」**。
2. 它会问你几件事（装到哪个盘、能力后端怎么来……）——**照着选就行**，不确定就用它推荐的。
3. 剩下的它自己安装：运行时来自 **python.org**、依赖来自 **PyPI** —— **不需要 git，也不需要 GitHub**。
   **客户端不再下载转写/分离/唤醒模型**；语音转写需要配对能力后端（Qwen3-ASR）。

## 快路那条命令（不绕助手）

资料夹里已经把那些步骤固化成了一个脚本（`echo-core\scripts\install-all.ps1`，
**装的东西与助手那条路完全一样**）：

```powershell
# 在这个文件夹里打开 PowerShell，跑这一条（-Yes = 不提问，全默认）
powershell -NoProfile -ExecutionPolicy Bypass -File ".\echo-core\scripts\install-all.ps1" -Yes

# 智能体只有一套 DSH（官方桌面端自带的 dsh）；不装智能体就写 -Agent none
powershell -NoProfile -ExecutionPolicy Bypass -File ".\echo-core\scripts\install-all.ps1" `
    -Yes -Agent dsh
```

它会**一次走完**：解包就位 → 建运行时 → 装核心依赖 → 写设置/自检（含拉起 DSH）→
**打印面板地址**。`-Engines` / `-Wake` / `-Diarize` 已废弃（传了只警告、不生效）；
`-DshDir` / `-AskDsh` / `-HarnessSource` / `-DshVersion` / `-PinHarnessCommand` 也已退役
（不再有 npm 安装或"已有 DSH 目录"这一问）。
包里有 `bundle\` 时再加 `-Offline`，就是 `装我.cmd` 双击出来的那一套（不下载运行时/依赖；包里也没有模型）。

## 包里有什么

| 文件 | 说明 |
|---|---|
| `装我.cmd` | **双击这个**：问安装位置、确保官方 DeepSeek Harness 桌面端已装、最后问后端怎么来，然后装完并打印面板地址 |
| `ECHO-kit-*.zip` | 主程序包。**只有它、没有解开的 `echo-core\` 时**，`装我.cmd` 会自己解到 `echo-kit\` 再装 |
| `ECHO-backend-portable-*.zip` | 可选：**后端薄包**（20 MB，源码 + 解释器）。选"本机跑后端"时要用 |
| `ECHO-backend-offline-*.zip` | 可选：**后端离线包**（薄包 + 装好依赖的运行时）。有它 = 本机跑后端**零下载** |
| `echo-core\` | ECHO 主程序（**已经解开好了**，约 10 MB，必备）。交给助手去装，你不用管 |
| `echo-install/` | 安装技能：`SKILL.md`（给助手看的步骤）+ `scripts/` 里的脚本 |
| `bundle\` | 可选：离线载荷（依赖 wheel + 兜底运行环境）。有它就**装的时候不下载**；**不再含模型** |
| `BUILD-INFO.txt` / `SHA256SUMS.txt` | 这个包的身份与各文件校验值（可选，想核对时用） |

> `install.ps1` 在 **`echo-core\scripts\` 里** —— 主程序已经解开放在那儿了，助手直接用它安装，
> **你不需要再解压任何东西**。如果你的助手说"找不到 install.ps1"，把这句话发给它就行。

装完助手会**登记安装结果**，所以打开 ECHO 会**直接进仪表盘**（不会再把你塞进向导页）。
万一还有没装好的，面板顶部会明确写"还缺什么、怎么补"，不用自己猜。

## 装完大概是这样

- 安装目录约 **0.2 GB**（主程序 + 运行环境；不再装模型）；**没有预装的运行时**，
  助手会按需拉一个 CPython 并装依赖（首次几分钟，取决于网速）。
- 装完能用：**录音 → 本机转成文字**、**会议录音 + 文字稿**、按 `Ctrl + Shift + E` 呼出面板、
  按 `Ctrl + Alt + C` 说一句话。
- 想要**自动写会议纪要 / 把纪要归档进笔记库 / 语音指令**：只需要官方 **DeepSeek Harness
  桌面端**（安装器会保证它已装）—— ECHO 会拉起它自带的 dsh，**不需要 Node.js**。
  `dshAutoStart`（默认开）控制"ECHO 启动时自动拉起 DSH"；面板里的**「打开 DSH 界面」**
  可以跳到它。无头运行**不需要登录**；第一次打开桌面界面时可能弹一次桌面端登录，按需登录即可。
- **录音、文字稿、数据库都在你自己电脑上**。默认会出网的只有语音朗读（把**被朗读的那段文字**
  发给微软）；想全离线就在设置里把「语音合成引擎」换成 SAPI。

## 遇到问题

- 助手说 **「找不到 install.ps1」**：**包没缺东西** —— 它在主程序 zip 里面，先解开主包就有
  （`echo-core\scripts\install.ps1`）。把上面那段话发给助手即可。
- 双击 `装我.cmd` 报 **「install-all.ps1 was not found」**：整个 kit 要**连着文件夹一起**解开
  （`echo-core\` 与 `装我.cmd` 必须同级），别只把 `.cmd` 拖出来。**或者**：把
  `ECHO-kit-*.zip` 与 `装我.cmd` 放在同一层，双击时它会**自己解开**（从 2026-10-01 起支持）。
- 装的时候弹出 `You must install or update .NET` 或 `WebView2 初始化失败`：那是**右缘浮动条**要的，
  与 ECHO 本体无关。**新版会自动判**：没装 .NET 就不起浮动条、直接用浏览器面板，不再弹这个框；
  旧包见到时也不用装 .NET —— 浏览器打开 `http://127.0.0.1:<端口>/` 即可。
- 智能体（纪要 / 归档 / 语音指令）没起来：先看面板「组件」里 `dsh` 的状态。DSH 只有一套 ——
  官方 DeepSeek Harness 桌面端自带的 dsh；没有就重跑安装器（它会下载并静默安装官方桌面端）。
  **不需要 Node.js / npm**。装好后 ECHO 随启动自动拉起干活的 DSH；面板「打开 DSH 界面」可跳到它。
- 安装官方桌面端时报「已有程序在运行」：先退出 DeepSeek Harness（托盘也退）再重跑；不退出也能继续，
  安装器会用现有的 CLI，只是不升级程序文件。
- 助手报 **`DLL load failed` / 「找不到指定的模块」**（装 torch、sherpa-onnx 这类组件时）：
  你的 Windows 缺 **Microsoft Visual C++ 2015-2022 运行库**。助手会自动下载安装它
  （会弹一次 UAC 授权框，点「是」）；装不了就自己装这个再让助手重跑：
  `https://aka.ms/vs/17/release/vc_redist.x64.exe`（装完可能要重启一次）。
- 其它任何卡住/报错：**把那段输出原样发回来**就行。

## 附带的维护脚本（`ECHO-运维\`）

这一层的 `ECHO-运维\` 里是**日常运维工具**，不参与安装，双击里面的 `.cmd` 就能用：

| 双击 | 用途 |
|---|---|
| `1-备份ECHO会议数据.cmd` | 清理/重装前备份会议数据（数据库一致性快照 + `meeting\` 目录 + 各表 JSONL） |
| `2-清理ECHO.cmd` | 彻底清理 ECHO（**没有会议数据备份会拒绝执行**；录音中拒绝执行） |
| `3-还原ECHO会议数据.cmd` | 重装后把会议数据还原回去（默认只还原会议相关的 7 张表，保留新装的设置） |
| `4-启动ECHO.cmd` / `5-停止ECHO.cmd` / `6-重启ECHO.cmd` | 启停与重启（录音/转写中会拒绝，`-Force` 才强停） |
| `7-状态ECHO.cmd` | 只读体检：服务/端口/组件/会议总数与最近一场/目录/进程；`-LogTail 30` 附带日志尾部 |

升级安装如果卡在「启动 ECHO 服务」，先双击 `7-状态ECHO.cmd -LogTail 30`（或看
`ECHO-运维\先读我.md`）—— 它会直接告诉你服务为什么没起来（缺依赖 / 残留实例占端口 / 策略拦启动……）。
