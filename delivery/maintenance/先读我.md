# ECHO 运维目录（备份 / 清理 / 还原 / 启停 / 状态）

> 用途：ECHO 这次升级改动较大，建议**清干净重装**，但**会议数据不能丢**。
> 这套脚本把「备份 → 清理 → 重装 → 还原」拆成四步，每步都可单独核对；
> 另附日常运维要用的**启动 / 停止 / 重启 / 状态**。

| 文件 | 双击它做什么 |
|---|---|
| `1-备份ECHO会议数据.cmd` | 把数据库快照 + `meeting\` 会议目录（录音/转写/纪要）+ 各表 JSONL 备份到 `<盘>\ECHO-backup\ECHO-<时间戳>\` |
| `2-清理ECHO.cmd` | 停进程、删自启动/快捷方式/计划任务/防火墙/注册表登记、删安装目录与缓存；**没有备份就拒绝执行** |
| `3-还原ECHO会议数据.cmd` | 把备份里的会议数据合并回（新装的）ECHO，自动停/起并核对会议场数 |
| `4-启动ECHO.cmd` | 后台启动 ECHO（已在跑就不重复启动），拉起看门狗；打印面板地址 |
| `5-停止ECHO.cmd` | 停止服务 + 边条 + 看门狗 + 切换器监督进程；**录音/转写中会拒绝**（`-Force` 才强停） |
| `6-重启ECHO.cmd` | 先停再起，自动恢复看门狗；录音/转写中同样会拒绝 |
| `7-状态ECHO.cmd` | 只读体检：服务/端口/运行时长、组件状态、会议总数与最近一场、关键目录、磁盘、进程；可加 `-LogTail 30` 看日志 |
| `py\`、`_echo-common.ps1` | 脚本内部使用，别单独运行 |

旧装是 `D:\ECHO`（ECHO 3.0，`echo-core\` 布局），脚本也兼容老式扁平布局。
换机器/换目录时用 `-Root` 指定，例如 `powershell -File .\7-状态ECHO.ps1 -Root "E:\ECHO"`。

---

## 一、备份（第一次务必先跑）

双击 `1-备份ECHO会议数据.cmd`。它会：

1. 自动找到 ECHO 安装目录，读出**真实的会议目录**（用 `/api/paths/env`，自定义过目录也不会漏）；
2. 用 SQLite 在线备份接口取数据库**一致性快照**——**不用停 ECHO**，WAL 下也不会拿到坏库；
3. 整目录复制 `meeting\`（录音分段 `.flac`、`meta.json`、`transcript.md`、`summary.md`、`topics.md`、`meeting_note.md`）；
4. 备份 `data\deleted-meetings`（历史删过的会议），并导出 `db-tables\*.jsonl`、`settings.json`；
5. 写 `manifest.json`（数量/大小/SHA256）和《恢复说明.md》，并核对源/目标文件数。

结果大致长这样：

```text
D:\ECHO-backup\ECHO-20261102-103000\
  echo.db                ← 数据库快照（会议/说话人/转写行/纪要记录/声纹）
  meeting\               ← 每场会议一个目录（含录音）
  db-tables\             ← 各表 JSONL + settings.json（纯文本，便于核对）
  deleted-meetings\      ← 有才存在
  config\                ← backend.json 等（可选恢复）
  manifest.json
  恢复说明.md
```

常用参数：

| 参数 | 作用 |
|---|---|
| `-Dest "E:\备份\ECHO"` | 指定备份目录（默认安装目录同级 `ECHO-backup\`） |
| `-NoAudio` | 不备录音，只备数据库 + 转写 + 纪要（体积从十几 GB 降到几十 MB） |
| `-Force` | 正在录音/转写时也强行备份（可能拿到半场音频，不推荐） |

完整参数直接看 `1-备份ECHO会议数据.ps1` 头部注释。

> 备份在**安装目录之外**，清理不会删它；仍建议拷一份到另一块盘或网盘。
> 备份期间 ECHO 照常可用；如果正在录音会**拒绝**，等录音结束再跑。

## 二、清理

先看清单（不删东西）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\2-清理ECHO.ps1" -DryRun
```

确认无误后双击 `2-清理ECHO.cmd`，按提示输入 `CLEAN` 才会开始。

会删：

- 进程：ECHO 服务（python）、看门狗 `startup.ps1`、切换器 `echo-supervisor.ps1`、边条 `echo-sidebar.exe` + WebView2 子进程、失败转移代理 `dsh-failover\proxy.py`；
- 自启动：启动文件夹里的 `ECHO*.lnk`、`%USERPROFILE%\.echo-switch\`（含 `echo-switch-startup.vbs`）；
- 快捷方式：开始菜单、桌面里指向 ECHO 的 `.lnk/.url`；
- 计划任务：动作路径在安装目录下的任务；防火墙规则 `ECHO …`；注册表 Run 项、`HKCU\Software\Classes\echo`（若存在）；
- 目录：`D:\ECHO\` 整个安装目录、`%LOCALAPPDATA%\ECHO`（DSH 视图缓存）、`%LOCALAPPDATA%\echo-sidebar`（WebView2 缓存）、`.echo-switch`、`.echo-instances.json`。

**默认不碰**：

| 不删的东西 | 原因 |
|---|---|
| `D:\ECHO-backup\` 备份 | 会议数据 |
| `D:\ECHO-delivery\` 安装包 | 重装要用 |
| `C:\echo-dev\` 源码树（git 仓库） | 开发用；要删加 `-IncludeSourceTree` |
| 桌面 `ECHO\` 工具箱、`.echo-test`、`.echo-tls`、`echo-backups` | 开发/个人工具；要删加 `-IncludeDev` |
| 笔记库（Obsidian）里的纪要 | 属笔记库，ECHO 清理不影响 |
| 新装的 DeepSeek Harness 桌面版 | 不是 ECHO 的进程 |

清理完会写《清理记录-时间戳.txt》到脚本目录和备份目录各一份，并列出仍存在的 ECHO 兄弟目录（如历史 `ECHO-stable-aside-*`）供你手工处理。

## 三、重装

双击交付包里的 `装我.cmd`（例如 `D:\ECHO-delivery\ECHO-delivery-20261101-2342\装我.cmd`），装到默认或你指定的目录。
它会问装到哪、是否已有 DSH、后端（会议转写那台 GPU 机器）怎么接。

## 四、还原会议数据

双击 `3-还原ECHO会议数据.cmd`。默认「只还原会议数据」：

- 把备份里 **7 张会议相关表**合并进新库：`meetings / speakers / lines / summary_runs / meeting_sessions / voiceprints / speaker_embeddings`，**行 id 原样保留**，所以会议目录、说话人、转写行天然对得上；
- **不动新装的设置**（设备、热键、后端配对、智能体配置都是新的）；
- 把 `meeting\` 会议目录合并回去（新装的 `AGENTS.md` 保留新版，不覆盖）；
- 自动停 ECHO → 改库 → 起 ECHO → 用 API 核对会议场数与备份一致。

如果新库里已经有会议数据，脚本会**拒绝合并**并列出冲突行数；确认要覆盖再加 `-Replace`。

想连**旧设置**一起恢复（整库替换）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\3-还原ECHO会议数据.ps1" -Mode Full
```

它会把新装的库先备份成 `echo.db.before-restore-<时间戳>` 再替换，出问题可退回。

还原后核对清单：

1. 面板地址打开，会议列表场数正确；
2. 随便开一场：录音能播放、转写分段在、纪要（summary）在；
3. 需要再转写/再生成纪要的，面板里按需操作（转写由能力后端负责，与客户端重装无关）。

## 五、日常运维：启动 / 停止 / 重启 / 状态

| 场景 | 双击 |
|---|---|
| ECHO 没在跑（面板打不开、托盘里没它） | `4-启动ECHO.cmd` |
| 想彻底停掉（不删数据、不影响下次开机自启） | `5-停止ECHO.cmd` |
| 改了设置/装完组件要让它生效 | `6-重启ECHO.cmd` |
| 想问「现在到底什么状态」 | `7-状态ECHO.cmd`（可加 `-LogTail 30` 看日志尾部） |

细节：

- **启动**：后台拉起服务并等端口就绪，打印面板地址；会顺带恢复看门狗（ECHO 意外退出自动拉起）。已经在运行时不重复启动。`-OpenPanel` 可让它顺手按设置打开面板；不传则只启动（设置里「启动时自动显示折叠条」开着时，折叠条会自己出现）。
- **停止**：停服务 + 边条 + 看门狗 + 切换器监督进程；**不动数据库、不动自启动**，下次登录照旧自动启动。**录音/转写中会拒绝**，确认要中断加 `-Force`。
- **重启**：先停再起，默认恢复看门狗和切换器监督；同样默认拒绝打断录音。
- **状态**：只读，不改任何东西。内容：版本/端口/运行时长、各组件（服务、智能体 harness、转写、播报、热键、会议、说话人分离）、会议总数与最近一场、当前是否录音/转写、数据/会议/模型/DSH 目录、磁盘剩余、在跑的 ECHO 进程；`-Json` 输出机器可读 JSON（交给别人排障时用），`-LogTail N` 附带日志尾部。
- 面板/边条外观由 ECHO 自己的设置决定（右缘边条 / 应用窗口 / 浏览器）；想恢复桌面用法就双击桌面「ECHO 个人助理」快捷方式。

## 六、注意

- 模型、后端配对、智能体（DSH）属于**程序组件**，不在会议数据备份里；重装后按向导重新装/配对即可。
- 若 ECHO 装在非默认目录：备份/清理/还原三步都加 `-Root "你的目录"`。
- 脚本为 **UTF-8 with BOM** 的 PowerShell 5.1 兼容脚本；从邮件/IM 转发时别让工具改编码（否则中文会乱、脚本报 `CommandNotFoundException`）。
- 需要管理员权限才能删的项（极少，如 HKLM 登记）脚本会跳过并在记录里注明。
- **清理前建议先退出 DeepSeek Harness（DSH）窗口**：它的工作区可能在 `D:\ECHO\aide`，文件被占用会导致删不净。脚本会重试 3 次并如实报告残留，重启后再跑一次即可。
- **备份时如果正好有会议开始/结束**，最后会提示「数据库会议数与会议目录数不一致」——等那场会结束后**再备份一次**即可（新备份是带时间戳的新目录，清理脚本自动用最新的那份）。
- 清理脚本只动**当前安装**：切换器（`.echo-switch`）和边条缓存这类全局进程，只在本安装登记为「当前实例」时才会被结束；清理另一个旧安装不会误杀正在用的那套。
