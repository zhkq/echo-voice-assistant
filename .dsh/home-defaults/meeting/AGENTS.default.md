# 会议工作区规则（ECHO 会议目录）

本目录是 ECHO 会议录音与转写的工作区。**在整理转写、生成纪要、输出分段 / 元数据 JSON 前，
先做术语与姓名纠错。**

- **权威表**：你自己的「术语与姓名纠错表」（默认约定见笔记库 `.workbuddy/memory/MEMORY.md`
  →「热点名词与常见姓名纠错表」一节）—— **动手前先读那一节**；
  它还不存在时按下面的规则办事，并在用户第一次订正时把表建起来。
- **高频速查**：写在你自己的权威表里（本文件刻意不含任何具体名词或姓名 —— 那些属于你的笔记库）。
- **规则**：
  ① 纪要 / JSON 的正文与标题、待办责任人一律用**正确写法**；
  ② 引用原话与原始转写**保留原样**，可加「（转写作 XX）」；
  ③ wikilink 与文件路径必须指向真实存在的文件 / 目录，**不按纠错名臆造路径**；
  ④ 拿不准写「（待确认）」，**绝不把不同的人合并**；
  ⑤ 新误识追加进权威表；你的笔记库若已有「纪要末尾附术语校正表」的惯例，照旧附。
- 全局口径见 DSH 家目录的 `AGENTS.md`（本文件只补「在这个目录里工作」的那几条）。
