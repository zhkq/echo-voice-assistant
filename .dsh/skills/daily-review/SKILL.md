# 每日回顾（ECHO 语音委派）

## 用途

用户下班后**一次性口述**当天做了什么。本技能做四件事：

1. **登记**：把口述整理成条目，追加进笔记库里的当天工作日志；
2. **去重**：同一天多次口述时**追加**，绝不覆盖已有内容；
3. **查漏**：拿昨天的待办对照今天的口述，挑一件**真正可能漏了**的事问一句；
4. **播报**：输出一段口语文本供 ECHO 在车里朗读（这是唯一影响车内体验的输出）。

## 触发条件

指令文本里出现 **`【每日回顾】`** 时使用本技能。指令里会给：

- `笔记库根目录`：**这是权威**，不要用别的路径；
- `当前时间`：算"上午/下午"用；
- `【今日口述·原始转写】…【/原始转写】`：用户原话，**唯一真相**。

## 输出契约（硬性）

每一条回复都必须包含**恰好一段**：

```
【播报】口语化的两句话以内 + 最多一个问题（也可以只有确认、不带问题）【/播报】
```

- **不可以有 Markdown**（无列表、无编号、无加粗、无表格、无 `#`）；
- **数字与日期口语化**（说"十月六号"，不写 `2026-10-06`）；
- **长度**：目标 60 字以内，最多 120 字（它是**念**出来的）；
- **只问一个问题**：信息确认与遗漏检查**不要各问一个**，挑最要紧的；
- 播报段**之后不要再写正文**（ECHO 只读这一段）。

## 个性化：`profile`

**这个技能刻意只带骨架** —— 每个人的笔记库目录、日志格式、待办分类都不一样。规则放在
**`<笔记库根目录>/.echo/profile.md`**（下称 profile）。

**每次执行的第一步永远是：读 profile。**

- **读不到 → 先按下面的默认规则把这一轮做完**，然后在【播报】里**问一个问题**（见下），
  把用户的回答写进 profile，下次就按它来。
- 读到了 → 完全按 profile 走（它比本文档的默认值优先）。

### 首次（没有 profile）该问什么

**一轮只问一个**，按需分几轮问完（别一次抛一串）：

1. 工作日志放在库里的哪个目录/文件名？（默认：`工作日志/YYYY-MM-DD.md`）
2. 一条工作记成什么格式？（默认：编号条目，可带缩进子项）
3. 有没有固定的"待办分类"？（默认：不分类，统一放文件末尾的 `## 待办`）

问到的答案**原样写进 profile**（用下面的格式），并且**这一轮照常完成登记**——不要让用户
"先配置再使用"。

### profile 建议格式（自己维护，可增删）

```markdown
# ECHO 工作日志约定（本文件由技能自动维护，也可以自己改）

- 日志目录：工作日志
- 日志文件名：YYYY-MM-DD.md（日期减一天就是"昨天"）
- 时段分节：## 上午 / ## 下午（12:00 前算上午；用户明确说了时间就以用户为准）
- 条目格式：`1. 一句话`；子项用两格缩进 `  - …`
- 待办小节：## 待办（若有多个分类，列成子小节）
- 归档月目录：（可选）例如 `26年10月/` —— 只在用户明确要求时用
- 已确认的专项目录：（可选）名字 + 相对路径，一行一个
```

## 执行流程

### 1. 读事实，不要凭记忆

1. 读 **profile**（没有就按默认，并准备在播报里问一个问题）。
2. 读**今天的日志**（路径来自 profile）。**已存在就先读、再追加**；不存在就按 profile 的
   格式新建。
3. 读**昨天的日志**，只看它的待办部分 —— 用来做遗漏检查。
4. 同一天的多轮口述在**同一个会话**里，不确定"今天已经登记了什么"时**读文件确认**。

### 2. 整理并追加

- 一条工作 = 一个条目；一条口述里有多件事就拆成多条；
- **只追加**：不要删除、不要重排已有条目；
- 用户口述里有"做完了"的，可以在原条目上标注完成，但**不要删原文**。

### 3. 待办

口述里出现的"明天要做 / 待跟进 / 后续安排"写进 profile 指定的待办小节：

- **只追加**，不清空已有；
- 用户没说时间的，写"待跟进"即可，**不要替他编日期**。

### 4. 查漏（这一步最容易做差）

**只问一个问题。** 从下面挑最要紧的：① 口述里有歧义/缺关键信息的地方；② 昨天挂着、
今天既没提也没做的事项；③ 口述里提到的时间点值得记一条待办。

问完**不要自问自答**，也不要列举"你可能还漏了 1、2、3"。

### 5. 收尾

用户说"今天就这些""回顾结束"或明显表示结束时：核对一遍今天登记了什么（**只读文件确认**），
播报改成结束语，**不再问问题**。

## 已知边界

- 本技能**不负责**会议转写与会议纪要（那是会议模块 / `meeting-archive` 的事）。
- 原始转写是唯一真相。**宁可照原话登记 + 追问确认，也不要替用户编**。
- 目录**确实存在**才挂双向链接；不要臆造专项目录。
