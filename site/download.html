Install

安装步骤

Windows 与 macOS 只需要解压和按提示操作；Android 直接安装 APK。都不需要 Node.js，也不需要 npm。

Windows 10 / 11 x64

  1. 解压下载的 zip，保留完整目录结构。
  2. 双击顶层的 装我.cmd，选择安装目录（默认 D:\ECHO，没有 D 盘则 C:\ECHO）。
  3. 安装器会检查 DeepSeek Harness 桌面端；没有时会下载并静默安装，已有则直接复用。
  4. 按提示选择能力后端：粘贴管理员给的配对串、在本机起后端，或先跳过，之后在面板里补。

macOS 14+（Intel / Apple Silicon 通用）

  1. 解压下载的 zip，把整个文件夹交给 AI 助手，并说「按 echo-install 技能给我装 ECHO」。
  2. 或按包内 先读我.md 运行 echo-core/mac/setup_mac.sh。
  3. 首次启动按系统提示允许麦克风、辅助功能 / 输入监控。
  4. 面板默认在 http://127.0.0.1:8970/ 打开，端口以数据目录里的 echo-port.txt 为准。

Requirements

系统要求与内测说明

Windows

  • Windows 10 / 11，64 位
  • 磁盘可用空间 ≥ 5 GB
  • 安装时需要访问互联网

macOS

  • macOS 14.0 或更新
  • Intel 或 Apple Silicon
  • 已安装 Homebrew；磁盘可用空间 ≥ 5 GB；能上网

Android

  • Android 8.0 或更新（API 26+）
  • 允许安装未知来源应用
  • 能访问能力后端（同一网络或公网地址）

内测说明

  • 当前为内测阶段，版本号 0.9.0-beta，功能与兼容性可能继续调整。
  • 录音、转写与设置保存在本机数据目录。
  • Android 是 debug 包，正式上架前会换成 release 签名版。

语音转写需要能力后端（Qwen3-ASR）。首次安装可在向导里粘贴配对串；有 NVIDIA 显卡的机器也可以启动本机后端。
