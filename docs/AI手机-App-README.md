## 2. 关键决策（已定）

| 决策 | 结论 | 理由 |
|---|---|---|
| 页面 | **5 页**：首页 / 指令 / 会议 / 回顾 / 设置 | 首页做遥控器；三份历史各自成页；设置放配对与 MCP |
| 首页 | 状态 bar + 指令 / 会议 / 回顾三主控 + 最近动态 | 一屏不滚动；录音/回顾进行中时对应卡整行展开 |
| MCP 位置 | **App 内**，不是 ECHO 内 | Agent 要开手机麦、调手机 TTS；ECHO 不该对网络多开一个口 |
| MCP 传输 | 本机 `127.0.0.1:18790/mcp`，无会话、JSON-only、Bearer | 手机 Agent 在本机；无状态最好实现、最好重连 |
| 凭据 | 两套：App ↔ ECHO 用 ECHO Token；Agent ↔ App 用 MCP Token | Agent 拿不到 ECHO Token |
| 配对 | PC 发 6 位码 → App claim → Bearer | 复用 ECHO 既有配对；码 5 分钟、一次性、错 20 次锁 5 分钟 |
| 录音 | 手机本地先录，按段上传；ECHO 落盘/转写/纪要 | 手机发起 = 手机麦；断网也能先录 |
| 录音格式 | **16 kHz 单声道 PCM16 WAV**；m4a/amr 不收 | 会议段只认 WAV/FLAC；m4a/amr 直传 409/422；平台只能出 m4a/amr 时本地转 WAV |
| 回顾 | 手机只 `start` + `turn`/`submit` + `stop`；**绝不 `/go`** | `/go` 会开电脑的麦，手机在车里听不到 |
| 默认 | MCP 默认关；打开才起前台服务；只绑回环 | 最小暴露 |

## 3. 三个前提（不满足就要改方案）

1. **手机智能体是本机运行**，能连 `http://127.0.0.1:<port>`。
   云端 agent（豆包/Claude 云端等）连不到手机回环；需要平台侧端侧代理或公网通道，本文不覆盖。
2. **平台允许 App 起常驻前台服务**，并在其中监听回环端口。
   不允许时按主设计 §7.3 改用平台工具注册（同一份 schema），或只在前台可用。
3. **平台允许前台服务使用麦克风**。
   Android 14+ 后台开麦受限；不允许时 `echo_meeting_start` 返回 `foreground_required`，发通知让用户点开 App，**不假装已开始录音**。

1. **评审**：产品/App/ECHO 三方过一遍主设计 §0、§4、§6、§7；有异议先改文档。
2. **ECHO 侧验收**：按 [接口验收](AI手机-ECHO接口验收.md) 跑 1.1–1.6 与 22 条清单；把缺口排期。
