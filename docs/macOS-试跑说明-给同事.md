# ECHO macOS 试跑说明（请照着做，约 30–60 分钟）

> 这是一份"自查说明"，不是产品文档。**你不需要懂它的内部实现**：照着第 1–3 节把它跑起来，
> 把第 5 节的材料发回即可。**遇到失败不用自己排查**——把报错原文发回来就行，
> 有些项我们本来就知道在 mac 上还没做完（见第 6 节）。

---

## 0. 这是什么，为什么要你测

ECHO 是一个**本地运行的语音助理**（Windows 上已经用了一年多）：按热键/说唤醒词说话 →
本地转写成文字 → 交给大模型执行 → 语音念出结果；也能录会议、出纪要。

这次要你验证的**只是"它在 macOS 上能不能跑起来、哪些地方要系统授权"**。
包里**只有代码**（约 2.6 MB），不含模型权重、不含 Python 依赖——依赖现装，
模型按需下载，所以第一次会花点时间，属正常。

三点说明（先说清楚）：
- **数据都在你自己机器上**：录音、转写、数据库全部落本地目录，不上传。
- **两个功能会出网**：语音朗读默认用微软在线合成（edge-tts，会把**被朗读的那段文字**发到微软）；
  转写默认本地模型。不想出网就在设置里把「语音合成引擎」改成离线（SAPI/say）。
- **不要把公司机密内容读给它**：这是个测试版。

## 1. 准备（约 10 分钟）

| 要求 | 怎么确认 |
|---|---|
| macOS **14.0 或更新** | `sw_vers` |
| 已装 [Homebrew](https://brew.sh) | `brew -v`（没装的话第 2 节第一步会提示你） |
| 磁盘 ≥ 6 GB 空闲 | `df -h ~` |
| 能上网 | 首次要装依赖 |

解压（同目录里有个 `.sha256` 校验文件，建议先校验）：

```bash
shasum -a 256 -c ECHO-public-1.0.0-*.zip.sha256     # 应输出 OK
unzip ECHO-public-1.0.0-*.zip -d echo-mac
cd echo-mac
```

## 2. 装依赖并启动（10–20 分钟，首次较慢）

```bash
bash mac/setup_mac.sh     # 装 python@3.11 + portaudio → 建 venv → 装依赖
bash mac/start_mac.sh     # 启动 ECHO
```

- **`setup_mac.sh` 的完整输出请先留着**（第 5 节要发回；报错也发原文，别自己改）

## 3. 逐项检查（每项记"通过 / 失败 + 现象"）

| # | 做什么 | 期望 / **重点记录** |

## 6. 已知"还没做"的部分 —— 这些不算 bug，如实记录即可

- **代码签名与公证还没做**：所以第 4 项那个安全提示是**预期**的，正式交付版会没有。
- **mac 的原生"常驻宿主/边条 App"还没做完**：目前是过渡实现（启动脚本往进程里注入 mac 版实现），
  所以边条行为、开机自启、双击图标这类体验**这次先按现状记录**，不按"应该怎样"判断。
- **全局热键依赖一个可选库（pynput）并需要系统授权**：授权流程本身就是我们要测的结论之一。
- 转写默认模型的中文**可能输出繁体**（训练语料偏繁体），属已知现象，换引擎可解。
- 面板里凡是写着"Windows 专属"的选项在 mac 上不出现或不生效，属设计如此。

## 7. 出问题时的最小自救（可选）

- 服务没起来：看 `data/logs/echo-server.log` 最后几十行，把报错发回。
- 面板打不开：`cat data/echo-port.txt` 拿到真实端口，再访问 `http://127.0.0.1:<端口>`。
- 想彻底重来：`rm -rf venv data`，再跑一次 `bash mac/setup_mac.sh`（会重新下依赖）。
- 不想继续了：`bash mac/stop_mac.sh`，然后把这个目录删掉即可，不留后台进程。
