阅读提示

状态色：已连接 / 完成　离线 / 暂停 / 转写中　录音 / 失败　回顾　补传 / 进行中

首页原则：一屏不滚动；三块主控；状态 bar 只回答“能不能用”和“现在在做什么”。录音/回顾进行中时，对应卡片整行展开，另一块收起。

历史页原则：列表 + 详情；空态、加载、失败、离线四态都要有文案；失败绝不画成空态。删除/改设置等管理动作不放在 App。

MCP：App 承载，不是 ECHO；只绑 127.0.0.1；令牌鉴权；13 个工具；Agent 只见 MCP Token，不见 ECHO Token。
