## Release 正文原文

ECHO 2.0：**Windows / macOS 双平台一等公民**，以及**分层交付** —— 安装包从"几百 MB 的整包"变成约 3 MB 的纯代码，运行时与模型在安装时按需拉。

这一版把安装方式也改了：不再让人照着文档一步步装，而是**把文件夹交给你的 AI 助手，让它照 `echo-install` 技能装**。

## 下载哪个

| 你的系统 | 下这个 |
|---|---|
| Windows 10/11 x64 | `ECHO-kit-20260923-0052.zip` |
| macOS 14+（Intel / Apple 芯片通用） | `ECHO-kit-macos-20260923-0052.zip` |

## 怎么装（三句话）

1. **解压**下载的 zip（会得到一个文件夹）。
2. 把**整个文件夹**交给你的 AI 助手（Claude Code / Cursor / DSH……都可以）。
3. 跟它说：**「按 echo-install 这个技能给我装 ECHO」**。

助手会问你几件事（装到哪儿、要哪种转写、要不要唤醒词），照它推荐的选就行；剩下的它自己
下载安装——运行时来自 **python.org / Homebrew**、依赖来自 **PyPI**、模型来自
**ModelScope / hf-mirror 镜像**，**不需要 git，也不需要 GitHub**。

> 想手工装也可以：`ECHO\scripts\install.ps1`（Windows）或 `ECHO\mac\setup_mac.sh`（macOS），
> 详见包里的 `先读我.md` 与 `echo-install/SKILL.md`。

## 2.0 相对 1.0 的变化

**交付方式（D22/D23/D24）**
- 主包只装代码（约 3 MB，构建期硬校验：不含内网地址、凭据、模型权重、预置 venv）
- 运行时（CPython）、转写引擎、模型都拆成**组件**，装的时候按你机器的实际情况拉
- 另有**离线合集**供内网/无外网环境

**双平台**
- macOS 从"精简支持"升为一等公民：原生安装脚本、安装技能 mac 分支、与 Windows
  **共用同一份 `SKILL.md`**（内部按系统分支）
- 一个命令出两个平台的可交付包：`python scripts/build_kit.py`

**智能体后端（可选，二选一）**
- **DSH Desktop**（默认）：本机 43120 的 JSON-RPC
- **标准版 harness**（新增）：独立家目录、随 ECHO 启动、**本地永久安装**（冷启动约 10 秒，
  对照 npx 的 2 分 10 秒）；不需要装 DSH Desktop
- **支持"只装了一个 DSH"**：家目录不再写死，注册与令牌按实际存在的家目录走

**能力 provider 抽象**
- 转写 / 大模型 / 语音合成都走 provider，本地引擎与在线服务并列可选，并**标注是否会出网**

**其余**
- 首装向导（12 步）
- 大量排障可读性修复：被强杀留下的 WAL 自愈、快捷方式启动时找不到 node、系统代理毒化
  localhost 探活、token 落点被日志清理误伤、"停止 harness"留痕、安装日志带断点可续跑
- 分清"你选的是另一个"（`未使用`）与"它坏了"（`失败`）—— 这条以前会在安装结论、
  启动页和右缘折叠条三处误导用户

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11 x64；macOS **14.0+** |
| 磁盘 | ≥ 25 GB（依赖约 7 GB，模型按需下载；Windows + NVIDIA 更多） |
| 路径 | **建议纯英文**（个别依赖读不了非 ASCII 路径） |
| macOS 额外 | [Homebrew](https://brew.sh)（装 `python@3.11` + `portaudio`） |
| 执行层 | 指令执行与纪要生成需要一个智能体：**标准版 harness**（要求本机有 Node.js）或已装的 DSH Desktop；不装也能用转写、会议与面板 |

## 已知事项

- **macOS 包未做代码签名与公证**：首次运行会提示「来自身份不明的开发者」，右键 →「打开」，
  或到「系统设置 → 隐私与安全性」允许一次。
- **macOS 需要人工授权**：麦克风（录音）、辅助功能/输入监控（全局热键）——首次弹窗必须本人点。
- **Windows 缺 VC++ 2015-2022 运行库**时原生扩展会 `DLL load failed`；安装技能会自动下载安装
  （会弹一次 UAC）。干净镜像上常见。
- **agent 沙箱里安装**：这类环境通常没有控制台，且会定期回收后台进程。安装脚本是**幂等**的，
  断在中途直接重跑同一条命令即可；断点看 `<安装目录>\data\logs\install-<时间戳>.log`。
  （沙箱里"帮你打开面板"那一步可能失败——**不影响安装结果**。）
- Whisper 系列的中文可能输出**繁体**（训练语料偏繁体，与语言参数无关）。要简体请用
  `sensevoice` 或 `qwen3asr`。
- **「本地」指的是转写与存储在本机**：纪要与指令执行的文本会发给你配置的模型服务，
  默认语音合成用微软在线服务。要全程不出网：设置里把 `ttsEngine` 固定为 `sapi`，
  并只使用本机/内网模型服务。

## 关于本页的附件

附件就是上面那两个安装包（`ECHO-kit-*.zip`）。它们是**纯代码**：主程序 + 安装技能 + 说明，
由 `scripts/build-package.ps1` 按白名单打出，并在构建期硬校验——不含内网地址、凭据、
模型权重与预置 venv。

> v1.0.0 的 release 里写过「本页不提供整包下载」：那说的是**含预置 venv 与已授权模型的内部整包**
> （它含单位内网信息，不适合公开分发）——**那个仍然不在本仓库**。本页这两个是代码包，两回事。
