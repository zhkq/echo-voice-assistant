## Release 正文原文

# ECHO v2.0.1 — 补丁版

修 2.0.0 装机后会踩到的几处硬伤：**会议转不出文字**、**装了 GPU 其实在跑 CPU**、
**侧栏全是「未分组」**。安装方式与 2.0.0 完全一样，无需换流程。

## 修了什么

### 会议转出来是空的（三个 bug 叠在一起）

- **选了 qwen3asr 却从来没装 `qwen-asr`。** 安装器的引擎表写的是
  `transformers modelscope torch`，还把 transformers 顶到 5.x（`qwen-asr 0.0.6` 只兼容
  4.57.6），而组件自检因为"transformers 能 import"照样显示**已就绪**。真正的报错要到
  转写时才出现：`RuntimeError: qwen-asr package is required for Qwen3-ASR`。
- **说话人分离一失败，整场转写陪葬。** 分离抛异常时转写行少一列（说话人），落库时
  `ValueError: not enough values to unpack (expected 5, got 4)` —— 几十分钟的转写成果
  全丢、状态变 error。现在形状归一，分离坏了也照常出文字稿，失败原因写进日志。
- **说话人分离自己缺依赖。** `-Diarize` 只装了 `pyannote.audio`，漏了它要的
  `speechbrain`（运行时才报 `No module named 'speechbrain'`，正是上一颗雷的引线）。
  现在与官方 `install_pyannote.py` 的装法逐字对齐。
- **会议时间戳骨架是"没说出口的依赖"。** `sensevoice` 自己不出时间戳，非得靠
  `whisper-small` + `faster-whisper` 对齐；漏了**不会报错**，只会安静地转出一场
  「（未检测到有效语音）」的空文件。选 `sensevoice` 时安装器现在会自动补上，并单独自检。

### 装了 GPU，其实一直在跑 CPU

`-AccelCuda` 原来只是往 pip 列表里加了个 `torch`（**没换索引**）——PyPI 上的 Windows
torch 是 CPU 版，装完 `torch.cuda.is_available()` 是 `False`。现在从 PyTorch 官方
`cu128` 索引装，并在自检里**实测** `cuda.is_available()`，不达标就判失败。
（cu128 同时修好 faster-whisper 的 `cublas64_12.dll is not found`。）

### 侧栏多了两个分组

装完自动建好（也可以随时调 `POST /api/dsh/workspaces/ensure` 重建）：

| 分组 | 目录 |
|---|---|
| 「会议空间」 | `{安装目录}/data/meetings` |
| 「指令空间」 | `{安装目录}/data/command` |

以后每场会议的会话进「会议空间」，默认指令会话进「指令空间」，不再是「未分组」。
分组名可在设置里改（`meetingWorkspaceTitle` / `commandWorkspaceTitle`）；
**你自己改过名的工作区一律不动**。

### 状态说实话

一场会一行都没转出来时，原来状态仍写 `transcribed`（面板显示成功、纪要写着"没内容"，
真正原因只在 stderr 里）。现在标 `error`，并把原因写进日志与会议备注。

## 下载哪个

| 你的系统 | 下这个 |
|---|---|
| Windows 10/11 x64 | `ECHO-kit-20260923-1252.zip` |
| macOS 14+（Intel / Apple 芯片通用） | `ECHO-kit-macos-20260923-1252.zip` |

**怎么装（三句话）**：解压 → 把**整个文件夹**交给你的 AI 助手 → 跟它说
**「按 echo-install 这个技能给我装 ECHO」**。不需要 git，也不需要 GitHub。

## 已经在跑 2.0.0 的，不用重装

- **qwen3asr 用户**：`powershell -File scripts\install-qwen3asr.ps1`
  （装 `qwen-asr==0.0.6` + `transformers==4.57.6` + `accelerate==1.12.0`）
- **说话人分离**：`pip install "speechbrain>=1.0,<2"`，或重跑组件脚本加 `-Diarize`
- **GPU**：
  `pip install --force-reinstall torch torchaudio --index-url https://download.pytorch.org/whl/cu128`
- **两个分组**：重启一次 ECHO 就会自动建好

> 修完之后，之前转成空文件的会议可以直接在面板上**重新转写**（原录音都在，不会丢）。

## 全量自检

Windows gate：**955 个用例通过**（9 skipped），compileall / import 冒烟 / 平台契约 /
ruff 全过。本机（Windows + RTX 5060）实测：71 分钟的会议（8 段）重新转写后
transcript 从 68 B 变成 64 KB，746 行、10 个说话人。
