## 四、重装稳定版（用 `D:\ECHO-delivery` 里最新的 Windows 包）

1. 把最新的 `ECHO-delivery-<时间戳>.zip` **解压到短路径**（如 `C:\ECHO-install\`；
   不要直接在微信/企微缓存目录里双击——虽然已修长路径，短路径更稳）。
2. 双击 `装我.cmd` → 安装位置建议填 **`D:\ECHO`**。
   - 装到 `D:\ECHO` = **升级模式**：会复用 `D:\ECHO\data`（含后端配对）、`meeting`（历史）、
     `backend`、`models`、`runtime-core`，**会议历史直接还在**。
   - 要全新就从空目录装（历史仍在备份里，可事后恢复）。
3. 安装器会：解 kit → 建运行时 → 装依赖（离线 bundle）→ **确保官方桌面版已装**（没装则联网下载）→
   写 `agentBackend=dsh` + `dshAutoStart=true` → 起 DSH 并轮询到 online → 自检。
   - 官方桌面版**正在运行**时 NSIS 安装器会拒绝覆盖（exit 2）：安装前先退出桌面版。
   - **目标机器不能联网 / 下载不通时（旁路安装）**：把
     `D:\ECHO-delivery\official-dsh-latest-windows-x64.exe`（约 276 MB，签名 Valid）
     拷到目标机器上、放在 **`装我.cmd` 同目录**，再重跑 `装我.cmd`。安装器会自动找到它并用它装
     官方桌面端（日志里是 `using side-loaded official installer`），不需要联网。
     也可以设环境变量 `ECHO_DSH_INSTALLER=<exe 全路径>`。
4. 装完会打印面板地址（默认 `http://127.0.0.1:8970/`）。
5. 之后**随时可以打开桌面版**：ECHO 会起无头 dsh 与它**共存，共用同一个 `~/.dsh`**
   （面板 `DSH` 行显示「与桌面版共用家目录」；两个进程同时读写 —— 官方未承诺并发安全，见第七节）。

## 六、回滚 / 恢复方法（出错时先看这里）

**会话/技能/登录丢了**（清 `~/.dsh` 之后想找回）：
```powershell
# 1) 完全退出桌面版与 ECHO（托盘退出）
# 2) 整个家目录恢复（/XJ 是必须的：绕开 node_modules junction）
robocopy D:\dsh-backup-20261103-1430\home $env:USERPROFILE\.dsh /E /XJ
# 3) 只恢复技能（可选，若是 18 个合并版）
robocopy D:\dsh-skills-consolidated-20261103\skills $env:USERPROFILE\.dsh\skills /E
# 4) 重开桌面版（可能要重新登录；ECHO 重装后会自动用这个家目录）
```

**会议历史要恢复**（比如装到空目录后）：
```powershell
# 先停 ECHO（确认没有会议在录）
robocopy D:\ECHO-backup-20261103-1410\meeting D:\ECHO\meeting /E
Copy-Item D:\ECHO-backup-20261103-1410\echo.db D:\ECHO\data\echo.db -Force
```

**代码/行为要回退**：重装旧包（`ECHO-delivery-20261103-1414.zip` 或 `1323`），或 `git checkout 86d37218`。

**重装后 DSH 起不来**：先看 `D:\ECHO\data\logs\` 与 `%USERPROFILE%\.dsh`；确认官方桌面端已装、
`resources\runtime\cli\bin\dsh.cmd` 存在；必要时在面板「设置 → 智能体」里点「启动」。

## 七、必须记住的注意事项（容易出错的地方）

1. **备份目录不要删**：`D:\ECHO-backup-20261103-1410`、`D:\dsh-backup-20261103-1430`、
   `D:\dsh-skills-consolidated-20261103`。这三个是这次重装的唯一退路。
2. **`~/.dsh` = 当前对话 + 桌面版登录 + 共用家目录**：清它之前先备份；清它之后桌面版需要重新登录。
3. **两进程共存是"用户拍板 + 实测可跑"，不是官方支持**：
   - 无头 dsh（ECHO 起，43199）与桌面版（GUI）**同时写 `~/.dsh`**；
   - 已知官方没有并发保证；**别在两边同时做大量写操作**（例如桌面版里同时大规模整理会话、
     而 ECHO 又在建会议/回顾）；
   - 出现会话异常/工作区对不上：先退出桌面版与 ECHO → 用第六节恢复 `~/.dsh` → 重开。
4. **桌面版没有"普通浏览器访问"开关**（当前 0.2.1-rc.5 官方版就没有，别再找）：
   ECHO 不能直连 GUI，只能无头共存。**不要再按老文档去改 `dsh-desktop.mode`**。
5. **长路径**：包装在深层目录（微信缓存等）时点安装会踩 Windows 260 字符；包装器已用 robocopy 修复，
   安装器里"是否已装 DSH / 怎么装"的三个 P0（空 `dsh\app` 误判、`-Agent none` 静默跳过、数组 splat
   导致 helper 不执行）也已修 —— 但仍建议解压到 `C:\` 下短路径。
6. **别再用两套 dsh**：不要给 ECHO 再建独立 DSH 家目录、不要再装 npm/Node 版 harness。
   程序只来自官方桌面端自带的 `dsh.cmd`。
7. **不要去动 `C:\echo-dev`**（dev 代码树/仓库）；它是以后继续开发的入口。
   桌面工具包 `C:\Users\zhkq\Desktop\ECHO\` 还在，但里面 `2-启动-稳定版` / `5/6-切换` 之类
   依赖已删除的 `~/.echo-instances.json`，**现在点了会失败**；只装稳定版用不到它们。
8. **dev/stable 切换器已随清理删除**：只装一套稳定版不需要；以后要 dev/stable 并存，
   再跑 `scripts\install-switcher.ps1` 重新安装切换器。
9. 安装包内的 `docs/项目进展-2026-11-03-一套DSH.md` 是完整背景；
   本文件是操作版清单。两份冲突时以本文件为准（时间更近）。
10. **备份不需要时也别急着删**：至少等新稳定版跑通一周、会议/回顾都正常后再考虑清理备份。
